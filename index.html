🔗 Hubungkan Google Sheets

Kirim dan ambil data penjualan/pembelian dari spreadsheet agar perangkat lain dapat memperbarui data.

Integrasi

Belum terhubung. Masukkan URL Web App setelah Apps Script dipasang dan diterbitkan.

Perlu disiapkan satu kali: buat Google Sheet kosong, buka Ekstensi → Apps Script, hapus isi bawaan lalu tempel seluruh isi file Triyakita_Apps_Script.gs, lalu Deploy → New deployment → Web app. Pilih “Execute as: Me” dan akses “Anyone” jika sesuai dengan kebijakan akun Anda. Salin URL berakhiran /exec ke kolom di atas. Jangan masukkan kata sandi Google ke aplikasi ini.
Sinkronisasi otomatis: setelah URL Web App disimpan, setiap transaksi selesai akan langsung mengirim data ke Google Sheets tanpa perlu menekan tombol sinkronisasi. Perangkat harus terhubung ke internet dan aplikasi/browser tetap terbuka. Untuk keamanan, URL Web App bertindak seperti alamat akses integrasi; bagikan dengan hati-hati. Tombol kirim data tetap tersedia untuk mengirim ulang data secara manual.

Tab yang dibuat di spreadsheet: Penjualan, Detail Item, Pembelian, Ringkasan Bulanan, dan Menu. Susunan kolom selalu tetap. Transaksi lama tidak diduplikasi dan tidak hilang walau data aplikasi sudah di-nol-kan lewat Tutup Buku.

Triyakita Kasir • Data lokal tersimpan di browser perangkat ini. Tombol Segarkan memperbarui tampilan perangkat ini; agar data sama di perangkat lain diperlukan database bersama. Unduh cadangan secara berkala.
